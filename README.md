# 🛍️ Grace Shop

Интернет-магазин, разработанный в рамках учебного проекта с использованием React и TypeScript.

🌐 [Посмотреть работающий сайт](https://kseniia-front.github.io/grace-shop/)

## 📌 О проекте

Grace Shop — веб-приложение интернет-магазина с каталогом товаров, карточками продуктов и корзиной покупок.

Проект создан для практического освоения frontend-разработки, работы с компонентами React, управления состоянием приложения и организации структуры проекта.

## 🚀 Технологии

- React
- TypeScript
- JavaScript (ES6+)
- Redux
- React Router
- SCSS / CSS3
- HTML5
- Git / GitHub
- npm

## ⚙️ Функциональность

- Отображение каталога товаров
- Просмотр подробной информации о товаре
- Поиск товаров
- Сортировка товаров
- Разделение товаров по категориям
- Добавление товаров в корзину
- Управление количеством товаров в корзине
- Подсчёт общей стоимости покупки
- Навигация между страницами приложения

## 💻 Запуск проекта

Для запуска проекта локально:

1. Клонировать репозиторий:

```bash
git clone https://github.com/Kseniia-front/grace-shop.git
```

2. Перейти в папку проекта:

```bash
cd grace-shop
```

3. Установить зависимости:

```bash
npm install
```

4. Запустить приложение:

```bash
npm start
```
